Dirección de Arte Digital & Ingeniería Web

WebAtelier: Precisión Visual, Rendimiento y Anti-AI Design

Una Skill profesional para agentes de inteligencia artificial diseñada para concebir experiencias web que transmitan la limpieza de Apple Design, aprovechen la flexibilidad de WordPress y erradiquen de raíz cualquier huella de plantilla automática o código genérico.

Obtener Skill en GitHub Probar Auditor DOM en Vivo

Arquitectura Multidimensional

Cuatro pilares de ingeniería y estética que eliminan la improvisación técnica en los agentes de IA.

Filosofía Apple HIG & WordPress Contemporáneo

Claridad visual absoluta donde el contenido es el protagonista. Implementación de Block Themes nativos en WordPress, configuración theme.json v3 y la Interactivity API para eliminar dependencias obsoletas y maquetar con radios concéntricos matemáticos ($n=4$).

Tokens Semánticos · Regla 60-30-10 · Cero colores hardcodeados

Diseño Adaptable en 3 Dimensiones

Móviles (toques de 44×44px), PC (CSS Grid dinámico) y Smart TV (10-foot UI) con navegación por cruceta D-Pad y estados de foco :focus-visible de alto impacto visual.

Mobile · Desktop · Smart TV

Motor 3D de Rendimiento Controlado

WebGL y WebGPU en tiempo real con Three.js y Spline. Protocolo estricto de descarte de VRAM (dispose()) y pausa automática fuera de pantalla con IntersectionObserver.

VRAM Cleanup · GPU Accelerated · Reduced Motion

Blindaje Activo Anti-AI Design

Erradicación sistemática de huellas digitales de IA: cero degradados morado-azul en titulares, cero resplandores neón artificiales, cero palabras en cursiva solitaria para fingir sofisticación, cero badges "AI-Powered", cero sopa de divs y erradicación del vocabulario cliché (*AI Slop*).

Cero Degradados en Texto · Cero Emojis en Titulares · Código Semántico

Instalación en tu Entorno de Agentes

WebAtelier es compatible con Pi, Codex, Claude Code, Cursor y cualquier asistente que soporte el estándar abierto de Agent Skills.

git clone https://github.com/BenjaminMurga/WebAtelier.git
cp -r WebAtelier ~/.agents/skills/web-atelier
cd WebAtelier && npm test
